netdash

Network dashboard and settings board for OPNsense. This is its package repository.

Install

1. On the OPNsense (SSH or console, option 8), add this repository:

pkg add https://noronus.github.io/netdash/os-netdash-repo.pkg

2. In the web GUI: System → Firmware → Plugins, reload the list, install os-netdash.

3. Open Services → netdash and sign in with an OPNsense administrator account.

Source, documentation and issues: github.com/Noronus/netdash
